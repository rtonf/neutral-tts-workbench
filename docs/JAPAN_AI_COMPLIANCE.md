# 日本法・AI指針への対応と確認範囲

確認基準日：2026年9月13日。対象は個人開発の未署名Windows用ソース配置版と、利用者の端末で実行する固定モデルの統合です。提供責任者はGitHubアカウントrtonfです。
以下は実装・文書による対応と限界であり、個別利用の適法性、全学習データの権利処理、日本法への完全適合、政府認証を保証するものではありません。

| 原則 | 現在の対応・証拠 | 未確認事項・対応方針 |

| 1：概要開示・知財保護 | [モデル名・固定版・ライセンス](INFERENCE_COMPONENTS.md)、lock/inventory/SBOM、下記処理、VOICE_USE、PRIVACY、[相談](ABUSE_REPORTING.md)、[検証](WINDOWS_ACCEPTANCE.md)、変更履歴を公開対象にする | 全学習データの来歴・個別許諾を保有せず再監査できない。全侵害を阻止する内容フィルター・本人認証・C2PA署名はない。申告・AudioSeal・ハッシュの限界を開示 |
| 2：権利者等の照会 | 相談の入口と資格・目的・対象を確認する手順を記載。自ら保有する構成・変更・検証記録を確認し、回答できない上流データは理由と開発者名を案内 | 学習包含のURL検索はできない。専用非公開窓口は未設置。公開時の最小Issue受付から非公開手段を確認できるまで機微資料は受領しない。正式受入れの前に安全な受領手段と運用開始時期を具体化 |

体制がないとの説明だけで、正式受入れ後の説明責任が完了するとは扱いません。
この版は実施事項と限界の公表であり、正式受入れや3原則の全面実施をうたうリリースではありません。

## データ処理と責任分担

- 自ら付加した部分はローカルGUI/CLI、実tokenizerプレビュー、固定取得、制限付きロード、AudioSeal統合、保存・復旧と説明です。
- 参照を条件として既存モデルが推論し、codecで音声を出力します。声ごとの追加学習や重みの更新は行いません。
- このアプリによる独自の学習用クロール・データ収集・再学習・RAGはありません。取得は公式固定ファイルのダウンロードです。
- 上流の設計・学習方法・データ来歴は[固定モデルカード](https://huggingface.co/Aratako/Irodori-TTS-v4-Small/blob/4c92c7ee2bb15c19a97cf4e86d24fd6bf33b0135/README.md)等で公表された範囲まで確認でき、全データの許諾証明とは扱いません。
- 非公開試験では許可を申告された約3.47秒・3.44秒の参照2本を使用。元音声・生成サンプル・個人資料は配布しません。話者類似度・初見利用者試験は未評価です。
- 原文は永続保存せず、計画・WAVのSHA・時間等を端末内履歴に保持します。中央監視はありません。法的証拠を残す必要がある利用者は、自分の権限・保管方針に従い別途保存してください。

責任者rtonfが公開前、依存/機能変更時、具体的な侵害・重大不具合の申出時に影響と対策を見直します。
継続提供中は少なくとも年1回、制度・上流条件・本書を確認し、変更要旨をRelease notesへ記録する方針です。常時監視・期限内解決を約束するものではありません。
対応記録は公開ソースから分離し、必要以上に収集・公表しません。提供を終了する場合は保守状況を公開先で案内する方針です。

確認した固定構成と用途の範囲では、ソース配置版の公開を具体的に禁止する条件との不整合は発見していません。
ただし上流学習データ、個別許諾、提供者自身の責任、正式コード受入れの運用まで確定したものではありません。
特定の声の商用提供、他社素材、具体的侵害の申出等は該当利用を保留し、権利者・上流開発者・知財/IT分野の弁護士へ確認します。
制度・届出は所管窓口へ確認し、個人資料は無断で外部送信しません。この候補の公開判断と、利用者の個別の生成・公開判断は別です。
