# 音声を使う前に：権利・同意・利用者の責任

このアプリは、参照WAVを条件として、既存モデルで入力文の日本語音声を生成します。
利用者による声ごとの追加学習は必要ありません。権利と許可を確認した音声を使用してください。
声の似かたや音質は、録音・話者・入力文などによって変わります。

## 参照音声の許可は3つに分けて確認する

1. **録音を使う権利**：自分が必要な権利を持つ録音、または権利者から今回の目的に合った許可を得た録音を使ってください。
2. **声の複製への明示同意**：話者本人が、その声を参照して新しい発話を生成することに明示的に同意しているか確認してください。録音・試聴の許可だけでこの同意を推定しないでください。
3. **生成音声の用途**：非公開試験、ネット公開、広告、収益化、販売、再配布、第三者提供など、許された範囲と期間・表示条件を確認してください。私的試験の許可を別の用途へ広げないでください。

話者本人の許可だけでは、録音物、実演、台本・文章、音楽、放送・配信素材などの権利まで処理されたとは限りません。
録音した人・制作会社・実演家・著作者など、関係する権利と許可を確認してください。
公開サイト、SNS、動画、配信、販売素材から入手できること自体は、声の複製や生成物の公開許可を意味しません。
他の音声合成サービスの出力を参照する場合も、そのサービスと音声・キャラクター等の利用条件を確認してください。

参照登録では、3項目の確認欄と自由記述を端末内に保存します。これは**利用者の申告の記録**であり、
権利者の本人確認、許諾の真偽や有効性の認証、法律相談の代行ではありません。
許可の対象・取得元・用途・期間・制限を、自分で説明できるように保存してください。
申告文や任意の根拠資料は非公開で保管し、公開Issueに貼り付けないでください。

## 入力・生成・公開時の注意

採用モデルが求める、声の複製への明示同意と用途条件にも従ってください。
著作権上の例外が適用されると考えた場合も、それを理由にモデルの同意条件を省略しないでください。
条件の詳細は[第三者部品の条件](INFERENCE_COMPONENTS.md)にあります。

無許可の声の複製、本人が実際に発言したと誤認させる利用、詐欺、名誉毀損、プライバシー侵害その他の違法な利用をしないでください。
第三者の権利を侵害すると考えられる入力・生成物は使用せず、許可と内容を再確認してください。
生成物の公開前には、自分で聞いて内容と使用範囲を確認してください。
合成音声であることが受け手に適切に伝わる表示と文脈にし、本人の発言・推薦・出演と誤認させないでください。
例えば説明欄や音声を聞く前の案内に「AIで生成した合成音声です」と示し、切り抜きでも誤認を生まない配置を考えてください。
この表示をしただけで、権利侵害になる内容や許可範囲外の利用が許されるものではありません。

AudioSeal透かしの検出、ハッシュ照合、同意チェックは、本人性・許諾・適法性を証明しません。
透かしには誤検出・未検出があり、加工による除去、なりすまし、権利侵害や訴訟を防ぐ保証はありません。

## できることと、確認できていないこと

参照WAVは1～4本、各30秒・6 MiB以内、mono（1チャンネル）・PCM16・44.1/48 kHzに対応します。
拡張子がWAVでも、形式が違うファイルは登録できません。30秒は受付上限で、品質の保証条件ではありません。
実機試験に使った参照は約3.47秒と約3.44秒の2本、合計約6.91秒です。
短文・通常文・長文の聞き取りと目立つ異常がないことについて試聴評価を受けています。
30秒1本による実生成、話者類似度、初見の初心者が補助なしで導入できることは評価していません。

必要なものは、利用許可を確認したWAV、読み上げる文章、対応PC、Python 3.13 x64/Tcl・Tk、
モデル・依存物を取得する初回通信と空き容量です。検証したPC構成と手順は[README](../README.md)を参照してください。
初回セットアップには16 GiB以上の空き容量が必要で、生成WAVやバックアップには追加容量が必要です。
