# 権利侵害・悪用の相談

声の無断利用、許可範囲外の生成、本人の発言との誤認、権利情報の誤りなどの相談は、公開後の
[rtonf/neutral-tts-workbenchのIssue](https://github.com/rtonf/neutral-tts-workbench/issues)で、まず**個人情報を含めずに連絡方法を相談**してください。
公開前はこのリポジトリの窓口は利用できません。提供責任者はGitHubアカウントrtonfです。
この版では専用の非公開フォームやメール窓口を設置していません。
GitHubの非公開脆弱性報告は[セキュリティ問題](../SECURITY.md)用で、一般の権利相談の受付を保証する窓口ではありません。

## 最初の公開連絡に書くこと

- 件名：「権利・利用に関する非公開連絡方法の相談」
- 本文：アプリのversion/commit、一般的な種別（声の利用、表示、ライセンス情報など）、非公開で相談したい旨。
- 公開しても個人情報や被害の拡散にならない場合だけ、問題の概要や対象のアプリ文書名。

**個人音声、生成サンプル、同意書、身分証、氏名・連絡先、非公開URL、私有パス、入力文、被害者を特定する情報を公開Issueに載せないでください。**
被害のある音声へのリンクも、初回の公開連絡には不要です。公開連絡自体が危険なら詳細を書き込まず、
掲載先プラットフォームの権利侵害報告窓口や、弁護士・法テラス等への相談を利用してください。

提供者が個別の非公開連絡方法と取扱条件を案内し、その方法を双方で確認できた場合に限り、
必要最小限の資料を送ってください。方法を用意できない間は機微な資料の送付を求めません。
非公開連絡では、申出人と権利との関係、対象・URL等、問題だと考える理由、許可された用途、希望する対応を確認します。
音声や証明資料が本当に必要かを先に相談し、不要な身分証や同意書全文を収集しません。

## 提供者の対応方針

相談が届いたら、提供者rtonfが、対象版・申出の内容・確認可能な根拠・対応経過を確認して記録します。
単なる申告や透かしだけで侵害・本人性を確定せず、必要に応じて追加説明や専門家の確認を求めます。
アプリや配布資料に問題があれば、説明修正、機能修正、該当配布物の公開停止等を検討し、可能な範囲で対応結果を案内します。
利用者が外部に公開した音声を強制削除したり、端末を遠隔操作したりする機能はありません。
外部サイトの削除・発信者情報等は、そのサイトの手続や法的手続で相談してください。

個人開発のため応答期限や解決結果は約束しませんが、権利救済を妨げないよう、合理的な期間で確認・回答するよう努めます。
申出は[プライバシー方針](PRIVACY.md)に従い、調査・連絡・再発防止・必要な法的対応のためにのみ使用します。
外部への資料提供が必要な場合は、目的・範囲・法的根拠を確認します。相談資料を公開デモや学習へ転用しません。

## 学習データ・出所に関する照会

アプリの固定モデル名、版、公式取得元、変更内容、保有する検証記録は確認できます。
上流モデルの全学習データや照会URLの学習包含を、この提供者が検索できる仕組みはありません。
確認できない場合はその範囲と理由、上流開発者名・公式資料を案内します。記録がないことを「学習に含まれない」と回答しません。
原則2・3に関わる個別照会では、資格・目的・照会対象などを非公開で確認できる手段を先に相談します。
通常の権利相談に、訴訟をしない等の誓約を一律に求めません。法令に基づく開示や法的救済をこの方針で妨げません。
